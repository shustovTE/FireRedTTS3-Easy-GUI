# Поиск спектральных провалов в Dialogs и Spontaneous

Аудит читает те же пары и нормализованные WAV, которые использует тренер FireRed. Учтён лимит 30 минут на спикера. Каждая реплика измеряется один раз внутри своей выборки и корпуса. Счётчики `target_draws_500` и `reference_draws_500` показывают, сколько раз она встречается в каждой роли за первые 500 обновлений (8 000 пар). Валидация учитывается отдельно. Для анализа достаточно CPU и подготовленных данных на Gauss.

```bash
cd /opt/firered-tuning
git pull --ff-only origin feat/russian-tts-adaptation
mkdir -p training/logs
OMP_NUM_THREADS=2 MKL_NUM_THREADS=2 nohup .venv/bin/python -u \
  -m fireredtts3_local.dataset_spectral_audit \
  > training/logs/dataset-spectral-audit.log 2>&1 < /dev/null &
```

```bash
tail -n 20 -f training/logs/dataset-spectral-audit.log
```

По завершении каталог отчёта появляется целиком. Для повторного анализа можно выбрать новый каталог через `--output`. По умолчанию создаются спектрограммы пяти разных записей из начала списка кандидатов. Число задаётся через `--plot-top`.

```bash
out=training/diagnostics/dataset-spectral-audit
jq '.groups[] | {split, corpus, clips, measurable_4k, candidates_4k, target_draws_500}' "$out/summary.json"
```

| Файл | Содержание |
|---|---|
| `summary.json` | Отпечаток отбора, числа записей и кандидатов по корпусу, выборке и полосе. Для сравнения в конце реплики знаменатель — `tail_comparable`. |
| `candidates.csv` | Одна строка на запись и подозрительную полосу. Сначала идут целевые полосы около 4 кГц. Есть путь к WAV, диктор, сила провала, время и показатели для той же записи на более ранних этапах. |
| `clips.csv` | Все записи, в том числе без замечаний, и их вклад в первые 500 обновлений. |
| `bands.csv` | Измерения каждой полосы для каждой реплики. Статусы показывают, хватило ли полосы пропускания и энергии по соседству. |
| `spectrograms/*.png` | Спектр финального WAV, усреднённый по активным кадрам в полусекундных окнах. Тёмные участки означают меньшую относительную мощность, белые — окна без измерений. Оранжевые линии отмечают полосу из связанной строки CSV. |

## Как читать измерения

Проверяются 3850–4150 Гц (окрестность провала из эксперимента с резонансами), 3400–4600 Гц (более широкая полоса из анализа генераций) и третьоктавные полосы с центрами от 315 Гц до 10 кГц в пределах частоты Найквиста исходного WAV. Для каждого активного 50-мс кадра мощность нормируется на общую мощность кадра. В окнах по 0,5 с скрипт сравнивает среднюю плотность мощности внутри полосы с более тихой из двух соседних полос. Положительное значение 6 дБ означает, что уровень в центре ниже каждой из соседних полос как минимум на 6 дБ.

- `persistent` — глубина от 6 дБ минимум в 65% измеримых окон и медианы от 6 дБ в первой и последней трети.
- `late` — медиана последней трети от 6 дБ, а глубина выросла минимум на 4 дБ относительно первой трети. Для сравнения требуется по два измеримых окна на каждом конце.
- `sustained_start_s` — начало первой серии из трёх соседних блоков с глубиной от 10 дБ. Такая серия может встретиться и в середине фразы. `strongest_s` — время окна с самым глубоким провалом.
- `before_levels_*` — та же полоса перед нормализацией громкости. У Spontaneous эта копия уже прошла DPDFNet8. `before_denoise_*` относится к копии после VAD перед шумоподавлением. Пустое числовое поле означает отсутствие измерения.

Ограничение по энергии исключает тишину и участки, где с одной стороны полосы почти нет сигнала. Обычный низкочастотный фильтр с монотонным спадом — отдельное явление. Пороговые значения служат для отбора записей на прослушивание. Форманты гласных, фонемный состав и микрофон тоже могут давать заметные провалы. При сравнении с генерациями полезнее повторение одной полосы на разных текстах и дикторах, чем один экстремальный кадр.
