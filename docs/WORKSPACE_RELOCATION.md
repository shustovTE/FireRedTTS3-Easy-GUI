# Перенос рабочего каталога в /opt/firered-tuning

Новые команды выполняются из `/opt/firered-tuning`. Репозиторий, `training`,
`models`, `.runtime` и виртуальные окружения уже должны быть перенесены вместе.
Настройки обучения, отбор данных и веса при этом не меняются.

В существующих manifests, рецептах, отчётах и служебных файлах виртуальных
окружений могут оставаться абсолютные пути `/home/firered-tuning/...`.
Не заменяйте их массовым `sed`: пути входят в контрольные хэши. Сохраняем
исходные файлы и делаем старое имя ссылкой на фактический новый каталог.

## Один раз после переноса

```bash
cd /opt/firered-tuning
git pull --ff-only origin feat/russian-tts-adaptation
python3 scripts/relocate_workspace.py --old-root /home/firered-tuning
```

Используется системный Python, установка пакетов не нужна. Команда создаёт:

```text
/home/firered-tuning -> /opt/firered-tuning
```

Это одна символическая ссылка, не вторая копия данных. Повтор команды безопасен.
Если старое имя занято другим каталогом или ссылкой, команда завершится ошибкой,
ничего не удаляя и не заменяя. Ссылка должна оставаться, пока используются
старые manifests, окружения, checkpoints или сохранённые рецепты.

Новые этапы подготовки используют фактический путь `/opt/firered-tuning`.
Уже подготовленные Scripted и объединённые VoxCPM-данные проходят аудит после
переноса: проверяются те же хэши аудио и manifests, а исторические пути
сопоставляются через существующую ссылку. Повторять VAD из-за переноса не нужно.
Старые рецепты и журналы сохраняют первоначальные пути как историю запуска.

## Продолжить VoxCPM2

Если отдельное окружение ещё не установлено:

```bash
.venv/bin/python -m fireredtts3_local.voxcpm_training setup
```

Если установка уже завершена, перенос сам по себе не требует скачивать модель
или переустанавливать зависимости. После создания ссылки работают и прежние
пути в editable install / shebang. Используйте явный новый путь к Python:

```bash
.venv-voxcpm2/bin/python -m fireredtts3_local.voxcpm_training --help
```

Проверить уже готовый объединённый набор, если он существует:

```bash
if [ -f training/datasets/voxcpm2-ru/report.json ]; then
  .venv-voxcpm2/bin/python -m fireredtts3_local.voxcpm_data audit \
    training/datasets/voxcpm2-ru
fi
```

Далее продолжайте с нужного этапа [инструкции VoxCPM2](VOXCPM2_RUSSIAN_LORA.md).
Не запускайте повторно уже работающую подготовку или обучение. Статусы и логи
теперь открываются из `/opt/firered-tuning/training/...`.

Исторические аудиты и resume FireRed не переводятся на новый формат путей;
не редактируйте их fingerprints вручную. Сохранённые Dialogs/Spontaneous
используются новым VoxCPM-процессом без повторного импорта.
